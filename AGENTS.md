# AGENTS.md

## ⚠️ This repo is build output — edit `../blog-src` instead

Every HTML/CSS/JS file here is **generated by [Zola](https://getzola.org)** and will be
overwritten on the next build. There is nothing to author in this repo.

- **Source repo:** `../blog-src` → `git@github.com:a5huynh/blog-src.git`
  — see `../blog-src/AGENTS.md` for posts, templates, styling, and build notes
- **This repo:** `git@github.com:a5huynh/a5huynh.github.com.git`
- **Published at:** https://a5huynh.github.io (GitHub Pages user site, served from `master`)

Generated here: `index.html`, `404.html`, `robots.txt`, `sitemap.xml`, `blog.css`,
`search_index.en.js`, `elasticlunr.min.js`, `posts/`, `tags/`, and the `static/`
passthrough dirs (`img/`, `files/`, `misc/`, `favicon/`, `webgl/`).

## Hand-maintained files

These exist only in this repo and must survive any sync:

- `.nojekyll` — stops GitHub Pages from running Jekyll over the output
- `README.md`, `.gitignore`, `AGENTS.md`
- `img/email.png`, `img/linkedin.png`, `img/twitter.png` — legacy assets still linked by old posts

Never `rm -rf` the repo root to "clean" before a copy.

## Syncing output

```sh
cd ../blog-src && zola build
rsync -a --delete --exclude '.git' --exclude '.nojekyll' --exclude 'README.md' \
      --exclude '.gitignore' --exclude 'AGENTS.md' --exclude 'img/email.png' \
      --exclude 'img/linkedin.png' --exclude 'img/twitter.png' \
      public/ ../a5huynh.github.com/
```

Then commit in **both** repos. There is no CI/GitHub Action — the build and copy are
manual, despite what `README.md` implies.

Check sync status at any time:

```sh
diff -rq ../blog-src/public . | grep -v '^Only in \.'
```

No output means in sync.

## Gotchas

- `base_url = "https://a5huynh.github.io"` is baked into the generated HTML as absolute
  URLs. Don't hand-rewrite them — change `config.toml` in `blog-src` and rebuild.
- `search_index.en.js` is ~1MB and regenerates on every build; a large diff is normal.
- The source was migrated to Zola 0.23.4 but **this output has not been regenerated
  since**, so the next sync will rewrite ~67 files. That churn is expected (less
  aggressive HTML escaping, new highlighter markup, recalculated word counts) — see
  `../blog-src/AGENTS.md`. Don't try to minimize it.
- `tags/index.html` is 0 bytes because `templates/tags/list.html` is empty upstream.
  That's a known upstream bug, not a broken copy.
